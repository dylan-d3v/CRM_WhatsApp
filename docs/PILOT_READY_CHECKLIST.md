# Checklist - Listo Para Vender (Piloto)

## 1) Producto

- [ ] Login y register funcionan sin errores.
- [ ] Onboarding crea negocio owner correctamente.
- [ ] Modulo clientes operativo (crear, buscar, editar).
- [ ] Modulo servicios operativo (crear, activar/desactivar, editar).
- [ ] Modulo citas operativo (crear, editar, cambiar estado).
- [ ] Dashboard diario muestra datos reales del negocio.
- [ ] Boton `Abrir WhatsApp` abre `wa.me` con mensaje prellenado.
- [ ] El producto NO afirma "mensaje enviado"; solo "WhatsApp abierto".
- [ ] Flujo usable desde movil (menu inferior visible y navegable).

## 2) Datos Demo

- [ ] Seed demo ejecutado (`supabase/demo/t12_pilot_demo_seed.sql`).
- [ ] Hay clientes con notas `[DEMO]`.
- [ ] Hay servicios `DEMO - ...` activos.
- [ ] Hay citas de hoy con al menos 3 estados diferentes.

## 3) Demo Comercial

- [ ] Demo ensayada con `docs/DEMO_SCRIPT.md`.
- [ ] Duracion medida: <= 3 minutos.
- [ ] Mensaje comercial claro: orden + seguimiento por WhatsApp.
- [ ] Cierre del piloto definido (instalacion + soporte inicial).

## 4) Operacion Piloto (Semana 1)

- [ ] Contacto owner confirmado (telefono y correo).
- [ ] Horario de acompanamiento acordado.
- [ ] Canal de soporte definido (WhatsApp).
- [ ] Responsable de cargar datos reales identificado.
- [ ] Fecha de inicio piloto pactada.
