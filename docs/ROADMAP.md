# Roadmap - CRM WhatsApp MVP

## Fase 1 - Demo Funcional

Objetivo: demo que se pueda mostrar a negocios locales.

Incluye:

1. Auth basica.
2. Clientes y servicios.
3. Citas con estados.
4. Dashboard simple.
5. Boton de WhatsApp con plantilla.
6. Diseno responsive.

Salida esperada:

- Producto demostrable en menos de 3 minutos.

## Fase 2 - MVP Vendible

Objetivo: usable por 3-5 negocios reales con soporte basico.

Incluye:

1. Plantillas editables completas.
2. Mejoras de validacion y UX movil.
3. Filtros y busqueda mas confiables.
4. Configuracion de negocio.
5. Exportacion CSV simple (opcional si agrega valor de venta).

Salida esperada:

- Primeros clientes pagando instalacion + mensualidad.

## Fase 3 - SaaS Basico

Objetivo: producto repetible para multiples negocios.

Incluye:

1. Multi-negocio robusto.
2. Roles owner/staff funcionales.
3. Suscripcion y estado de plan.
4. Admin basico interno.
5. Evolucion gradual hacia automatizaciones.

Salida esperada:

- Base solida para crecer como SaaS.

## Plan De 6 Semanas (Guia)

### Semana 1

- Inicializar proyecto
- Configurar stack base
- Auth + rutas protegidas

### Semana 2

- CRUD clientes
- CRUD servicios

### Semana 3

- CRUD citas
- Estados y flujo operativo diario

### Semana 4

- Dashboard
- WhatsApp `wa.me`

### Semana 5

- Plantillas editables
- Ajustes UX mobile-first

### Semana 6

- Pruebas end-to-end manuales
- Reforzar RLS
- Preparar demo comercial
